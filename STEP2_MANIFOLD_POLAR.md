# Step 2: bundled finite-dimensional projective manifold and polar covariance

This branch adds 8 theorem candidates and 6 named definitions to the 118-theorem extension. All named theorem and definition dependencies are audited. The target is a global ChartedSpace and IsManifold on Mathlib's actual projectivization with the quotient topology, using fixed finite-dimensional complex model C^(dim E - 1). The proof uses rank-nullity, explicit continuous linear projection onto chart kernels, homeomorphisms, open partial homeomorphisms, and smooth transition formulas. The polar covariance theorem composes actual polar component differentiation with the finite multiplet tensor identity; weights are Q times squared moduli and no independent logarithmic slopes are assumed. Positive polar probabilities are required at the point, and the normalized lift is given with differentiability and normalization. The earlier zero-safe theorem uses whole-vector normalization instead, without any component positivity. All results on this branch are candidates until CI passes. No changes to main; no custom axioms.
